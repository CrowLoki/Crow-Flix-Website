What Crow-Flix is

Crow-Flix is a real application installed on your Windows computer. It does not run inside this website. This official site explains the application and links directly to its verified GitHub release; watching, browsing, favourites, and playback all happen inside the Crow-Flix desktop window.

Live TV catalogue

Browse a searchable, categorised television catalogue with channel information and artwork fallbacks.

Programme guide

See what is live now and what is coming next without leaving the application.

Resilient playback

Supports HLS, MPEG-DASH, direct media routes, alternate sources, failover, and stall recovery.

My List

Keep favourites and recently viewed channels together in local app storage on your computer.

Web Library

Maintain a separate, user-controlled library of web destinations that open through the installed desktop app.

Crow identity

The approved mascot, Crow Bitfeather typography, Crow Talon pointers, and a custom electric blue and violet interface.

Inside the desktop app

The main Crow-Flix view keeps navigation, search, live programming information, and playback actions in one focused Windows interface.
